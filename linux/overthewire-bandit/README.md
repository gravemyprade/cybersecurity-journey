# OverTheWire — Bandit

Варгейм для освоєння основ Linux CLI. Кожен рівень дає пароль до наступного — проходиш усе через термінал по SSH: від базової навігації до мережевих утиліт, cron і git.

**Середовище:** Ubuntu у VirtualBox, підключення по SSH

> Паролі рівнів не публікуються за правилами OverTheWire — у розборах замість них `<пароль>`.

## Що охоплює
Навігація й робота з файлами · пошук (`find`, `grep`) · обробка тексту та даних · кодування і стиснення (base64, xxd, tar/gzip) · мережеві утиліти (`nc`, `openssl`) · cron · git.
